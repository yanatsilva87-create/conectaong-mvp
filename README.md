# ConectaONG

## Sobre o projeto

O ConectaONG é um MVP desenvolvido com o objetivo de apoiar a organização e divulgação de ações sociais da comunidade, facilitando o acesso às informações sobre campanhas, doações e oportunidades de voluntariado.

O projeto foi desenvolvido a partir das necessidades identificadas junto à comunidade parceira, utilizando práticas de levantamento de requisitos, prototipação, desenvolvimento e validação da solução.

## Funcionalidades do MVP

- Visualização de campanhas sociais;
- Cadastro e acompanhamento de doações;
- Consulta de oportunidades de voluntariado;
- Navegação entre as principais áreas da aplicação;
- Interface simples, responsiva e acessível.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- Visual Studio Code

## Estrutura do projeto

- `index.html` - página principal e campanhas sociais;
- `doacao.html` - área relacionada às doações;
- `voluntarios.html` - área de voluntariado;
- `css/` - arquivos de estilização;
- `js/` - arquivos JavaScript responsáveis pelas interações da aplicação.

## Controle de versão

O desenvolvimento utiliza Git e GitHub para registrar a evolução do MVP por meio de commits semânticos, branches e Pull Requests.

## Projeto acadêmico

Projeto desenvolvido na disciplina de Projeto de Software, na etapa de Execução e Evidências do Projeto de Software.
